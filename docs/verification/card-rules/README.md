对应设计 #83、实现 #84。基于PR#80的8f443ee，独立分支codex/card-rules-20261109。此增量不代表整个设计闭合，Windows尚未接入。

## 本轮变化

查询决策与卡片显示独立：词头朗读语种与原句语种分开；VoiceOver有Apple/macOS/辅助功能等证据时给名称说明，无身份依据时明确候选；README给惯用文件名称说明；Redis在部署/缓存语境给名称参考。现有术语资料继续复用，未知驼峰/代码名称不自动拿词典残片或拆词当主释义。拆词仅次级参考，不允许未知结果收藏。

中文语境与名称不自动翻译整段；普通外语词继续默认双语。名称原文按需展开，多术语中文语境默认保留。中文节选上限60字符、其他160字符；展开控制位于原文区。句译按用户请求翻译当前展示范围，收起或切换范围后旧任务结果不应用；手动句译不写通用查询缓存。百科统一由用户主动发起。

OCR相邻行不跨列表新项目或明显字号差异拼接。有依据的attention mask / padding token可整体查询。对于字号突出的、48字符内、含中点的全片假名标题，查询完整行；这只是明确的有限标题规则，不是通用标题分类器。

## 仍待完成

- 本轮仅首个增量：原型的混排术语可点击切换尚未接入原生卡片；当前需重新取词。
- OCR片段完整性、通用标题/路径结构及保留行元数据的数据契约尚未全面实现；阅读输入的列表边界仍需独立验证。长bank仍可能独立词义与句译不一致，不能宣称语境模型准确。
- 名称资料仍有限，本轮新增几个已确认类型的本机参考，不是训练得到的通用语境分类模型。
- 无词典的中文混排普通词缺独立译词服务回退，当前明确无可靠解释；缺包/超时物理UI及取消竞争需要专项验证。
- 实际混排/未知/按需句译/收藏全过程截图与物理手势仍待补；本轮不以AX和结构断言替代完整UI验收。
