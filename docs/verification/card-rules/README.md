# Mac 语境与卡片规则验收 · build14

设计 #83、Mac #84、PR #85（依赖 #80）；Windows 接入 #86 单独验收。

## 最终行为

查询对象、原文结构、参考来源分别判断。普通外语词默认适长双语；中文混排默认保留中文，点击才翻译当前展示范围；名称先说明、原文折叠；未知代码不把拆词当解释，不允许收藏。中文语境中的无词典普通英文词用独立英中请求，避免中文整句方向影响词义。正文中的其他英文词可点击，使用确切原文偏移重新查询。

阅读输入保留硬换行边界；OCR不拼接下一列表项、不同栏或明显字号变化。结构包含句子、列表、标题、路径和识别片段。中文节选最多60字符，其他160字符，保留命中词并用省略号标记裁切；展开仅当前块。明确短片假名标题整体查询；其他突出短标题提供“翻译整个标题”，正文不自动扩成标题。路径不机译；明确带省略号的不完整片段不自动句译。OCR无法可靠检测所有缺字，不能将几何规则描述为通用完整性模型。

句译请求拥有独立ID，收起/切换范围/新查询取消旧请求；失败给重试。简体输出统一规范化。收藏保存完整原文及其对应完整句译，节选译文不会误附给完整原文；新增可选来源/结构字段兼容旧记录。百科仅手动查询。
