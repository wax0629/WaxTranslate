# Windows 语境卡片规则验收

设计 #83；Windows #86 / PR #87 基于视觉 PR #82。两条 PR 按 #82 → #87 集成，Windows 单独验收。最终提交、CI 运行与下载包统一记录在 [Issue #86](https://github.com/wax0629/WaxTranslate/issues/86) 和 [PR #87](https://github.com/wax0629/WaxTranslate/pull/87)，不以旧提交或 Mac 成功替代。

## 行为与数据

名称先说明身份；中文混排不自动英译。其他英文术语按实际字符偏移点击查询，重复词和 emoji 不改变命中。词头与原文分开朗读，法语标题保留法语，中文语境保留中文语音。按需句译使用独立请求 ID，切换、收起、关闭后丢弃旧结果。中文句译由固定 SHA256 的 Argos zh_en 1.9 模型在本机执行，源码安装及便携包均提供。

标题可主动整译；列表、Markdown 标题、路径、片段与注释保持边界。注释可跨连续注释行，去掉每行 //，不带入相邻代码。识别片段在内存中保留，语义证据限定当前段落或结构块，不能拿另一段中的定义解释当前词。长原文节选保留命中词，中文上限 60 字、其他 160 字并保留完整词，展开只限当前块。

未知代码不能收藏或复制成可靠释义；百科由卡片按钮主动发起，成功保留来源，失败能重试。收藏保存相关原文、具体偏移、来源与结构；仅在译文对应完整相关原文时保存句译。SQLite 新增可选结构字段，旧调用默认 sentence，已有记录和复习时间不重写。

## 实际语义样例

下列结果使用 Windows 上的真实离线模型、词典及本机规则检查。对应 [test_card_rules.py](../../../windows/test_card_rules.py)，不是截图夹具中的固定译文。

| 样例 | 检查结果 |
| --- | --- |
| river bank / deposited ... bank | 句中释义分别为「岸」与「银行」 |
| macOS 辅助功能中的 VoiceOver | 名称参考：Apple 的屏幕朗读辅助功能，不自动翻译中文原文 |
| 人工听音与 VoiceOver | 身份不足，明确「当前片段不足以确认」 |
| film ... voice-over | 英汉词典参考「画外音」，不作为 Apple 产品解释 |
| README 文档列表 | 项目说明文件的惯用名称，不接入下一条 API |
| 字段用 INTEGER 存储整数 | 术语参考「整数类型」，不把大写词一律判作未知缩写 |
| 模型输入的 token 与访问 token | 前后两处分别为「词元」「令牌」，保留各自偏移 |
| UnknownSDK | 未确认代码名称，禁收藏，百科须手动查询 |
| Du pain frais，指定法语标题 | 单词参考「面包」，不自动整译；词头读法语 |
| Keep this door closed，主动翻译标题 | 进入完整选区翻译，得到含「门」的译文 |
| 多行 // avoid ... 后接 type/struct | 原文仅保留注释，移除标记，重复词偏移不变 |
| QRL 的定义在另一段 | 原始片段仍可诊断，释义不借用跨段定义 |

原有术语定义正向样文改为同一段，并新增跨段拒绝用例；原有 8003 字符识别片段及偏移回归继续保留，区分原始片段和可采用的局部证据。

## 复现

Windows 11 x64 本机使用 Python 3.12.8、PySide6 6.12.0，模型和数据库均在隔离目录；日常检查默认离屏。先按 README 安装依赖与全部开发语言包，再运行：

```powershell
.\.venv\Scripts\python.exe windows\check.py -v
$env:QT_SCALE_FACTOR = '1.5'
.\.venv\Scripts\python.exe windows\check.py -v
```

独立 Windows runner 使用实际打包后的 Python 3.12.10，在两档缩放分别执行 `runtime\python.exe windows\check.py --desktop -v`。完整门禁覆盖 107 项；本机离屏跳过其中三项真实桌面检查，由 runner 执行。新九项验收检查语义、标题、语音调用、结构边界、点击、取消及收藏读回。多语原生 OCR 另执行 2 项屏幕取词／框选和 16 项识别路由测试。

`WaxTranslate-Windows-Visuals` 包含宽窄四页、普通词、名称、混排、未知、错误与长译文卡片的 100%／150% 原生截图。manifest 同时记录实际尺寸、倍率、词头、可见文字与收藏状态。截图前重新展示卡片并等待桌面合成，解决旧 150% 未知词截图残留前一张 Redis 内容的问题。固定释义仅用于排版，真实语义由上表与完整检查分别验证。

旧 486b2f6 的 98 项两档桌面回归及 2+16 项 OCR 均已通过，但不是本次新增修复的最终证据。最终代码需以 PR 当前提交的完整 CI 和复核后的截图验收；过程中的失败保留在 Issue，不将未通过项标成成功。

## 验证边界

Windows 与 Mac 复用行为规则，模型输出不要求逐字相同。名称参考是可解释的本机规则，不是通用专名分类模型；未知名称不会凭拼写猜成解释。截图夹具与本机自动检查不等于全部第三方应用物理手势、人工听感或屏幕阅读器验收。这些仍由双端路线图 #3 跟踪，不阻止本轮已定义 Windows 范围交付。
