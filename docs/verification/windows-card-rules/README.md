# Windows 语境卡片规则验收

设计 #83，Mac #84 / PR #85 验证后接入，Windows #86 / PR #87 基于视觉 PR #82。规则代码与模型保持平台实现，统一用户行为。

## 行为与数据

名称优先解释，中文混排不自动英译；正文中的其他英文术语通过确切偏移查询。按需句译使用独立请求ID，切换/取消不显示过期结果。中文句译由固定SHA256的Argos zh_en 1.9模型在本机执行，便携包内置。未知代码不能收藏；百科手动发起，成功保留来源，失败能重试。节选最多中文60字符或其他160字符、完整词边界；展开仅当前项。收藏保存来源与结构，SQLite新增可选兼容字段，旧调用缺字段时默认sentence，复习计划保留。

标题、列表、路径、片段与注释边界有独立规则；代码注释去掉行首 //，不与相邻代码拼接。OCR不能保证识别所有缺字，名称资料也不是训练的分类模型。
