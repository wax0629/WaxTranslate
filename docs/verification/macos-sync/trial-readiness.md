# 试用准入复查 · 2026-11-09

负责人：Codex。关联 Issue #78 / PR #80；Windows 视觉同步关联 Issue #81 / PR #82。用户反馈的截图来自 build11，本轮修订为 0.3.0 build12。**只建议开发版有限试用，不宣称全面验收完成。**

## 两张截图说明了什么

- `INTEGER` 的词头和中文原句已取到，属于释义路径失败。build11 根据整个中文语境建立中文→英语会话；所选英文词原样返回时，被安全边界拒绝为可靠释义。之前英文样句里的 INTEGER 成功，不能覆盖此混排场景。
- `LookupTranslation` 是文件路径里的驼峰标识符。模型原样返回、词典及百科未收录时，旧版会显示未释义；百科没有精确条目并不代表 OCR 失败。不能凭文件名猜测代码功能。
- 原样返回保护继续保留。修订增加独立英语本机词典参考，整句仍按原语种翻译；驼峰标识符只在每个组成词均有词典依据时展示「名称组成词参考（不代表代码功能）」。没有依据时仍未释义，不保存为成功结果。

## 本轮验证

环境：本机 macOS 26.6.2 / Intel，Swift 6.3.3，安装英中/中英及日中语言包。测试只使用合成文本及隔离数据，不读取用户原图中的背景内容。

| 验证项 | 预期 | 实际结果 | 结论 |
| --- | --- | --- | --- |
| 中文语境 INTEGER | 原样返回时提供英语词典参考；不改整句方向 | 本机词典与真实中英会话得到「整数 · 词典参考」，句译仍为英语；未知原样词仍不作为成功结果 | 本机回归通过 |
| 文件路径 LookupTranslation.swift | 不虚构专名或代码功能 | 组成词参考为 Lookup「查表」、Translation「译文」，明确限制；不把这种组合当作函数说明 | 本机词典、真实中英会话及回归通过 |
| 未收录代码名 | 没有足够证据继续未释义 | QzxUnknown / UnknownSDK 反例通过，失败不写缓存 | 通过 |
| 旧功能回归 | 词边界、语境、保存、OCR等不退化 | `./scripts/check.sh` 包含真实 Vision、Apple英中/日中、magpie、bank、短语、混排术语、缓存和数据回归 | 本机通过；不是所有应用准确率结论 |
| 屏幕与物理手势 | 真实用户应用中端到端取词 | 本轮对截图对应文本做语义回归，未重复实际Codex鼠标悬停与物理Option；旧屏幕链路证据仅覆盖受控样文 | 本轮未执行，仍需用户试用确认 |

原句翻译和词义参考是不同证据。长 bank 样句仍可能主释义回退「银行」，整句译文却正确为河岸；不得记作该长句消歧通过。组成词参考也不等于标识符精确定义。
