# Windows 使用指南

首次安装或从源码启动请从[仓库首页](../README.md)开始。以下操作适用于 Windows 11 x64 开发版。

## 查词、框选与对照阅读

| 要做的事 | 操作 |
| --- | --- |
| 查屏幕上的词 | 把鼠标移到单词上，轻按并松开取词键，默认为左 Ctrl。轻微指偏也能命中。要查 `read/write` 的右半边，可指向 `write` 的字母中部。 |
| 翻译屏幕选区 | 按住取词键，用鼠标左键拖出矩形，保持取词键按下并松开鼠标。顶部应用菜单与托盘菜单也有「框选翻译」，Esc 可取消。 |
| 阅读可复制的文章 | 在「对照翻译」粘贴文章或点「试读示例」。启用「单击查词」后点词即查，拖动仍可选字；取消勾选即可定位编辑光标。也可双击或按 Alt+Enter 查词。 |
| 翻译并复制整段 | 在「对照翻译」按 Ctrl+Enter 翻译，按 Ctrl+Shift+C 复制。修改原文会清空旧译文。 |

单独长按 Ctrl 超过 350 毫秒再松开不会取词。Ctrl+C 和 Ctrl+单击仍交给前台应用；按住取词键并拖动属于框选手势。游戏或其他取词软件占用左 Ctrl 时，在「设置 → 屏幕取词键」选择右 Ctrl 或「仅应用内查词」。

## 看懂取词卡

Windows 视觉按已确认的 Mac 开发版统一：纸色背景、衬线英文、两排统计和棕红色卡片操作。顶部保留 Windows 窗口控制和应用菜单；页面不重复放「框选翻译」「打开对照翻译」按钮。Windows 继续使用随包的 Spectral 字体和本机中文字体，未复制 Apple 字体或平台控件。[视觉与验证记录](verification/windows-visual/README.md)

词头旁显示可用的音标和听读按钮，下面是语种、可用的词性和释义。「句中释义」表示从整句译文对齐到了所指的词；「单词参考」表示独立查询得到的词义。长句会优先显示足以理解当前词义的分句，点展开图标（「查看全句」）可展开。框选时先显示译文，点「查看原文」可对照。

中文混排中的英文词与中文原文分别判断：名称先解释，中文不自动整句英译；多术语原文中的其他英文词可直接点击重查，保留确切出现位置。点“翻译这段原文”才调用中文至英语离线模型。长原文按当前命中截短，展开只限当前项；路径不机译、不完整片段不冒充完整句子。突出短标题提供整体查询；代码注释去掉行首 //，不接相邻代码。未知名称禁止收藏；保存结构与来源兼容旧词本。

随包另提供中文至英语模型，仅服务中文语境的按需句译，不改变外文查词语种菜单。

当前原生界面、前后截图和试用包见 [PR #82](https://github.com/wax0629/WaxTranslate/pull/82)。

- **对照与收藏**　点「加入生词本」保存词、完整原句、句译和释义。同一词的不同语境可以分别保存。「更多操作」可复制或查看可用的词典来源。图钉可固定卡片，拖动顶部或留白可让开正文。普通卡片可用 Esc 或点击外部收起。
- **听读**　点扬声器听单词，旁边的箭头可选慢速或听原句，再点一次可停止。缺少声音时，在 Windows 语音设置中添加相应语种。
- **术语与来源**　文中给出缩写全称或明确定义时，卡片优先标出「文中定义」。英语还可查本地术语和 76 万余条英汉词典。百科仅由卡片的地球按钮主动发起，仅发送当前词条；未知名称不根据拼写推断含义，也不会自动联网。

## 语言与识字

| 获取方式 | 原文语言 | 译文 |
| --- | --- | --- |
| 随便携包提供，源码安装默认下载 | 英语、日语、韩语 | 简体中文 |
| 在「设置 → 语言包」下载 | 法语、德语、西班牙语、意大利语、葡萄牙语、俄语 | 简体中文 |

语言包显示「已安装」后即可使用，无需重启。英语直接译为简体中文，其他八种语言经英语在本机转译。词性模型和英汉词典用于英语。离线翻译使用 Argos 发布的模型，离线 OCR 使用 Tesseract 模型，日语和韩语分别用 Janome 与 MeCab-ko 分词。[识字模型来源](https://github.com/tesseract-ocr/tessdata_fast/tree/87416418657359cb625c412a48b6e1d6d41c29bd) · [英汉词典来源](https://github.com/skywind3000/ECDICT/tree/39cfb9672c0906b63569e0453c2e6abfb9ab182a)

屏幕取词使用 Windows OCR 和本地识字包。默认按所指的行和词判断语种。在音乐列表里，可指向歌名中的一个词查义，或单独框住整行翻译；遇到像 `I` 和 `l` 这样外形相近的字符，把相邻词一并框入可提供更多线索。单独查法语 `pain`（面包）或只含汉字的日文标题时，可在「设置 → 原文语言」指定语种后再查。「对照翻译」直接读取粘贴的文字。

日语可在没有空格的 `図書館で本を読む。` 中点「書」查「図書館」。韩语可在 `도서관에서` 中点名词部分查「도서관」。截图和识字过程在内存中完成，整句翻译在本机处理。

## 查词记录与复习

首页固定显示累计取词、已保存、待复习和已掌握四项。最近取词最多保留六个，显示词头、短释义和查询时间。同词同语种再次查询会置顶。框选和整段翻译不增加取词次数。

在「生词本」按 Ctrl+F 可搜索单词、释义或原句。开始复习后先看原句，再揭晓释义。「再学一次」安排在十分钟后，「记住了」按 1、3、7、14、30、60 天递增。连续三次选择「记住了」即计入已掌握。

## 托盘、更新与本机数据

有系统托盘时，最小化或关闭主窗口默认收回托盘，仍可取词。要退出，从托盘右键菜单点「退出」；关闭窗口的行为可在设置中调整。可以选择登录 Windows 时启动，默认关闭。没有系统托盘时会显示普通任务栏窗口。

更新便携版时先退出旧版，再把新包完整解压到另一目录。登录启动已开启且程序路径改变时，在设置中点「改用当前版本」。以下数据由同一 Windows 用户的各版本共用。

| 位置 | 内容 |
| --- | --- |
| `%LOCALAPPDATA%\WaxTranslate\notebook.sqlite3` | 查词计数、最近六个词、手动收藏的原句与句译、复习进度。旧版已有计数和词条继续保留。 |
| `%LOCALAPPDATA%\WaxTranslate\preferences.ini` | 取词键、窗口关闭方式等偏好。登录启动由 Windows 启动项管理。 |
| `%LOCALAPPDATA%\WaxTranslate\models` | 当前用户已安装的语言模型和词典资源，升级后可复用。 |
