# macOS 使用与开发

本轮 Mac 同步由 [Issue #78](https://github.com/wax0629/WaxTranslate/issues/78) 跟踪，开发版版本为 **0.3.0**。应用使用 SwiftUI/AppKit、Vision 和 Apple 本机翻译；沿用 bundle ID `local.luma.hovertranslate`、磁盘名 `waxtranlate.app` 和旧词本键。

## 安装与开始使用

需要 Swift 6、macOS 26.4 或更新 SDK。最低运行系统为 macOS 15.2。

```sh
./scripts/install.sh
open "$HOME/Applications/waxtranlate.app" --args --show
```

默认在菜单栏待命，点击漫画头像图标后选择「打开我靠翻译」显示主窗口。菜单栏与应用使用同一品牌图标。关闭主窗口仍可取词；通过菜单中的「退出我靠翻译」退出。设置可改为启动时显示主窗口，也可配置登录后待命。

「设置 → 启动与参考 → 在 Dock 中显示」即时切换 Dock 图标，重启后保留；默认关闭。关闭此项不退出应用、不关闭当前窗口，菜单栏始终保留打开入口。

| 操作 | 方法 |
| --- | --- |
| 屏幕取词 | 指向词语，轻按并松开 Option；设置可改为 ⌥⇧T、⌃⌥T，或关闭全局快捷键 |
| 框选翻译 | 按 ⌥⇧R / ⌃⌥R，或从应用/菜单栏菜单选择「框选翻译…」，拖选后松开；Esc 取消 |
| 对照阅读 | 在「对照翻译」粘贴或输入文章，双击原文中的词查词，点「翻译全文」或 ⌘Enter 翻译整段 |
| 查询结果 | 先看主要释义；普通外语词默认对照，中文语境按需句译；可听读、固定、复制、收藏，长句可展开完整原句 |
| 最近取词 | 首页显示最近六个词、实际释义和查询时间；点击可再次查询 |
| 保存与复习 | 点「加入生词本」，在「生词本 → 到期复习」显示释义后选「记住了」或「再学一次」 |
| 语种与权限 | 设置中选择自动识别或明确的源语言，检查系统语言包与屏幕录制授权 |

屏幕取词需要「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」中的既有授权。应用仅从明确的「权限设置」操作发起系统授权流程。语言包由 Apple 管理，设置和取词卡会显示可下载入口；下载后在本机翻译。非中文译为简体中文，中文译为英语。实际语种支持以当前系统为准，不能将 Windows 的九个模型安装状态视为 Mac 的安装状态。

Option 单键仅在 0.45 秒内按下并松开、且没有组合键、点击、拖动或滚动时触发；不会吞掉原应用事件。已有明确快捷键设置保留，新配置默认 Option。监听仅处理修饰键变化，通过系统事件计数判断是否混入其他输入，不读取按键文字；切换模式时卸载旧监听。

首页统计固定两排两列，卡片不随窗口横向拉长。页面不重复放置「框选翻译」或「打开对照翻译」按钮；阅读直接从顶部「对照翻译」进入，框选使用上述菜单或快捷键。

屏幕截图显式隐藏指针，并按所在显示器的实际倍率配置像素尺寸；裁切采用该显示器的局部坐标。小字号命中只允许少量垂直行内余量，不横向吸附相邻词。截图仍只在内存中处理。

松开 Option 后，光标旁先出现「正在取词…」。识别到词后，同一张卡片显示词头及按现有规则展示的原文，随后补上词义。等待时可以关闭卡片或直接查下一个词。已授权屏幕取词且启用了快捷键时，应用启动后在后台用一张固定文字小图预热 Vision。

首次悬停取景限制在光标附近最多 900 × 180 逻辑点；原文疑似裁切时最多补采一次，扩展至同一显示器内最多 1200 × 480 逻辑点。取消或发起新查询后停止后续处理；仍不完整时显示片段，只保留真实可见的同块文字。已安装英中包时，启动后台用固定本机样句预热，不下载包。相同词语、原句、语种和选中位置的译义最多在内存缓存 64 条、10 分钟；关闭应用即清空。简体中文输出统一转换繁体字，保存、复制与页面显示使用同一结果，原文不改写。

默认用 `./scripts/check-hover-feedback.sh` 在离屏图片上取词，运行准确模式 Vision，并把实际取词卡挂到隐藏窗口。有英中语言包时会核对句中释义与句译。窗口始终隐藏，每次使用独立偏好。用 `./scripts/check-hover-feedback.sh --compare 76a6526` 可与第一版等待卡对比。单测翻译会话使用 `./scripts/benchmark-macos.sh`，可加 `--reuse-session`。

需要复现遮挡、关卡或框选时，在独立桌面运行 `./scripts/check-hover-feedback.sh --desktop <截图目录>`。该模式会展示受控样文和取词卡。运行应用时加 `--trace-lookup`，标准错误仅记录阶段名及耗时。`lookup.card_shown` 对应词头，`lookup.excerpt_meaning` 对应长句中先得到的已确认释义，`lookup.complete` 对应翻译完成。[同机耗时与截图](verification/hover-feedback/README.md)

## 语境与参考的边界

连续 `rule out`、`run out of`、`look up` 及其常见变形按整组查询。例如在 `These results do not rule out infection.` 中指向 `out`，显示 `rule out`「排除」，句译保留否定。重复词使用实际命中的 UTF-16 位置；不跨标点或栏扩展短语。模型标记可能包含相邻成分，例如把 magpie 标成「喜鹊中」。对独立词的中文边缘虚词，用词典或独立词译核对完整词边界；有证据时采用对应词义，无法核实时回退到独立参考，不直接删除后缀。标记无法可靠对齐时，单独翻译词或短语并标为参考，保留可用的句译。

完整外语自然句中的普通词和已确认术语自动展示原文与对应译文，中文语境按需句译。不完整或未确认完整的原文显示片段，不自动句译，可明确点击“翻译可见片段”。短句完整显示；长句优先选取命中词所在的适长分句，否则以命中位置为中心，按完整单词截取约 160 字符（中文语境约 60 字符，保留完整命中词），单独翻译这一节选，避免将不同部分硬凑成对照。可展开完整原句及整句译文。收藏继续保存完整原句和整句译文；完整句译失败时保留主释义及节选对照，展开后明确提示。

孤立 `tulip` 等有本机英语词典证据的词优先按英语处理；没有词典时，对常用拉丁阅读语种复核一次，只有英语胜出时才替换原先的非列表语种猜测。完整非英语句子及明确的其他候选保留其判断，仍可手动指定源语言。英文缩写、常见工具名和多义术语沿用 Windows 的词表：命中明确的文中展开时显示「文中定义」，其余显示「术语参考」或「多义参考」。例如开发语境的 MVP 与体育语境的 MVP 不使用同一解释。文中定义只利用当前可见栏或编辑器里实际存在的文字，不恢复未截取内容。

词表数据由 `windows/terminology.py` 导出。修改 Windows 词表后运行 `python3 scripts/sync-reading-terms.py`；Mac 检查会拒绝词表漂移。Mac 的定义匹配实现有独立回归，当前未声称与 Windows 的全部句式规则逐项等价。

名称和缩写按命中的词语查本机术语，不要求整句是英语；中文段落中的 OCR/API 等同样给出全称和解释，卡片标为「术语释义」。原句语种和手动语言选择仍保留。中文语境可辅助区分 Codex、Rust、MVP、PRD 等含义，线索不足时显示多义参考；普通 ram/rest 和非英语同形词保持保守。

本机命中可立即复制与收藏，不等待系统模型或语言包；普通外语词、已确认术语及名称在外语自然句中默认显示同一节选的双语。中文语境保留短中文原文，用户点“翻译这段原文”后才附英语对照；中文语境中的名称原文可按需展开。词义无需等待句译即可使用。只有原样返回的拉丁名称会标为「暂未找到可靠释义」，不作为成功释义保存或放入缓存；日中共用字形（如猫）和整段代码保留反例。未收录名称仍可能需要独立参考，词库与语境规则不代表通用专名准确率保证。

百科由取词卡的地球图标手动查询。只发送当前词语，不发送原句、文章或截图；只接受精确同名结果，并在卡片中单独显示来源及链接。未找到、网络失败和同名歧义都有明确状态。音标、词性没有可靠数据时不填充。

## 数据与升级

旧词条保留 ID、原文、释义、原句、到期时间与连续记住次数。新增词条记录语种和精确位置；旧格式没有这些字段时仍可读取和复习。首页的「已掌握」指连续记住至少三次；「再学一次」清零并于十分钟后重现，记住后的复习间隔为 1、3、7、14、30、60 天。

累计与今日次数从本版实际完成的查询开始；最近六条查询保存在本机，重复查询会更新排序与时间。旧词本没有历史查询统计，不补造。关闭取词卡或发起新查询时旧任务应丢弃结果；编辑、取消或更换阅读语种后，过期全文译文不能回写。

数据仍在应用的本机偏好域，设置提供数据位置入口。遇到词本或活动数据无法解码时保留原始数据、显示错误，并禁止覆盖损坏部分。安装脚本复用现有签名材料；不要删除 `~/Library/Application Support/waxtranlate/BuildSigning`。本机升级备份存于 `~/Library/Application Support/waxtranlate/UpgradeBackups`，不提交到仓库。

## 复现验证

```sh
./scripts/check.sh
swift build -c release -j 2
```

检查使用隔离偏好域，覆盖真实 Vision OCR、精确命中、连续短语、非英语反例、旧词本、统计与跨日、最近六条、损坏数据保留、复习、过期阅读结果、术语歧义和百科请求边界。系统安装英中包时，另实测 Apple 翻译；未安装时明确打印跳过。GitHub Actions 的 macOS 工作流执行相同检查与 Release 构建，不修改屏幕录制权限。

真实界面回归需要手动完成：正常与窄窗首页；粘贴、全文翻译和双击第二个重复词；固定、展开、听读、复制与收藏；到期复习；更换快捷键与源语言；其他应用中的取词；框选与 Esc 取消。界面测试可用 `--test-profile WaxTranslate.Test.<唯一名称> --show` 启动隔离词本，完成后退出并删除该专用偏好域；不得使用真实用户词本作为测试夹具。安装签名、真实外部服务与界面验收的实测结果见 [本轮验收记录](verification/macos-sync/README.md)。


## 未释义与试用边界

词头已出现但显示「暂未找到可靠释义」通常表示已取到文字，翻译却原样返回，应用将其拒绝为成功释义；这和「没有识别到文字」不同。中文原句中的英文词独立查英语词义，整句只按需翻译；不能用中文→英语的原样词作为最终成功结果。代码驼峰名明确未确认，次级操作可提供有词典依据的组成词参考，不推断类、方法或文件功能；任一组成词未收录时仍可明确未释义。Wikidata 是百科，不能替代普通英语词典或源码分析。

可先在「对照翻译」输入同一句并双击词重查，区分屏幕 OCR 和释义路径。若仍失败，反馈应用版本、所选词、可公开的最短原句、源语言设置与是否首次查询。不要提供含私密内容的整屏截图。[试用准入和剩余验收](verification/macos-sync/trial-readiness.md)

## build16 语境与卡片规则（历史阶段）

外语自然句中的已确认名称/术语自动显示短原文与对应译文，中文语境仍按需句译。名称先判断身份，未知代码明确未确认，拆词只供次级参考且不能作为可靠解释收藏。中文多术语原文可直接点击另一个英文词，保留重复词的确切位置；英文词头与中文原文各按语种朗读。普通软换行可以接续，列表、Markdown标题、注释和代码分开；注释去掉行首 //，保留 URL 内的斜杠。标题可点“翻译整个标题”，路径不机译，明确的不完整片段不自动句译。

长原文只展开当前块；取消、收起和切换查询后不显示过期句译，失败可单独重试。来源和结构随收藏保存，节选译文不会误配完整原文；旧数据与复习计划保留。七类离屏原生布局和原先四类实机交互截图分别记录，不混用为翻译准确率结论。[完整验收与复现](verification/card-rules/README.md)。Windows对应规则已在[PR #87](https://github.com/wax0629/WaxTranslate/pull/87)单独验收并合入主分支。

本次规则修订由 #88 跟踪；[当前翻译逻辑](translation-logic.md)。


## build17 · 换行、断句与半句

文本先分结构块，再判断同一行碎块与跨行延续，最后断句并检查完整性；不会先把换行全部抹掉。连续注释去标记，列表保留当前项及续行，标题/代码/路径和明显段落/栏边界分别处理。小数、版本号、URL、常见缩写、引号与括号参与断句判断。

截图触及边缘或缺少可靠句首/句尾时，先尝试上述有界补采；仍无法确认的内容标为“原文片段”。可靠词义继续可读，只有用户点击才翻译可见片段。收藏和复习保留该标记，完整句与片段不会混用缓存。[规则与逻辑图](sentence-boundaries.md) · [本轮验收](verification/sentence-boundaries/README.md)。Windows本轮同步进度由[#90](https://github.com/wax0629/WaxTranslate/issues/90)单独记录。

## 公开试用核查修复（本地预览）

框选结果仅在主动收藏后保存，不再自动加入最近取词或统计。查词的原句和旧词本继续按原格式读取。百科参考统一为取词卡地球按钮手动查询，不再显示自动查询开关。

英语整句缺少可靠词义对齐时，会尝试保留确切位置的短语境，并利用完整原句恢复点中词的范围。必要时用包含该词的相邻名词组合定位，最多三种标记、至少两种结果一致后采用原始译文里的词义。成功后可正常收藏与缓存；证据不足仍明确显示未确认。无属性接口也有真实服务及模拟回归，最低 macOS 实机仍待检查。[长句修复与本地预览](verification/long-context/README.md) · [其他修复记录](verification/public-trial-fixes/README.md)
