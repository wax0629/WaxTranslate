# macOS 使用与开发

本轮 Mac 同步由 [Issue #78](https://github.com/wax0629/WaxTranslate/issues/78) 跟踪，开发版版本为 **0.3.0**。应用使用 SwiftUI/AppKit、Vision 和 Apple 本机翻译；沿用 bundle ID `local.luma.hovertranslate`、磁盘名 `waxtranlate.app` 和旧词本键。

## 安装与开始使用

需要 Swift 6、macOS 26.4 或更新 SDK。最低运行系统为 macOS 15.2。

```sh
./scripts/install.sh
open "$HOME/Applications/waxtranlate.app" --args --show
```

默认在菜单栏待命，点击书本图标后选择「打开我靠翻译」显示主窗口。关闭主窗口仍可取词；通过菜单中的「退出我靠翻译」退出。设置可改为启动时显示主窗口，也可配置登录后待命。

| 操作 | 方法 |
| --- | --- |
| 屏幕取词 | 指向词语，按 ⌥⇧T；设置可改为 ⌃⌥T，或关闭全局快捷键 |
| 框选翻译 | 按 ⌥⇧R / ⌃⌥R，或点「框选翻译」，拖选后松开；Esc 取消 |
| 对照阅读 | 在「对照翻译」粘贴或输入文章，双击原文中的词查词，点「翻译全文」或 ⌘Enter 翻译整段 |
| 查询结果 | 先看一条主要释义；可听读、固定、复制、收藏，或展开所在原句与整句译文 |
| 最近取词 | 首页显示最近六个词、实际释义和查询时间；点击可再次查询 |
| 保存与复习 | 点「加入生词本」，在「生词本 → 到期复习」显示释义后选「记住了」或「再学一次」 |
| 语种与权限 | 设置中选择自动识别或明确的源语言，检查系统语言包与屏幕录制授权 |

屏幕取词需要「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」中的既有授权。应用仅从明确的「权限设置」操作发起系统授权流程。语言包由 Apple 管理，设置和取词卡会显示可下载入口；下载后在本机翻译。非中文译为简体中文，中文译为英语。实际语种支持以当前系统为准，不能将 Windows 的九个模型安装状态视为 Mac 的安装状态。

## 语境与参考的边界

连续 `rule out`、`run out of`、`look up` 及其常见变形按整组查询。例如在 `These results do not rule out infection.` 中指向 `out`，显示 `rule out`「排除」，句译保留否定。重复词使用实际命中的 UTF-16 位置；不跨标点或栏扩展短语。标记无法可靠对齐时，单独翻译词或短语并标为参考，保留可用的句译。

孤立 `tulip` 等有本机英语词典证据的词优先按英语处理；没有词典时，对常用拉丁阅读语种复核一次，只有英语胜出时才替换原先的非列表语种猜测。完整非英语句子及明确的其他候选保留其判断，仍可手动指定源语言。英文缩写、常见工具名和多义术语沿用 Windows 的词表：命中明确的文中展开时显示「文中定义」，其余显示「术语参考」或「多义参考」。例如开发语境的 MVP 与体育语境的 MVP 不使用同一解释。文中定义只利用当前可见栏或编辑器里实际存在的文字，不恢复未截取内容。

词表数据由 `windows/terminology.py` 导出。修改 Windows 词表后运行 `python3 scripts/sync-reading-terms.py`；Mac 检查会拒绝词表漂移。Mac 的定义匹配实现有独立回归，当前未声称与 Windows 的全部句式规则逐项等价。

未知词可按设置自动查询 Wikidata，也可点击取词卡的地球图标手动查询。只发送当前词语，不发送原句、文章或截图；只接受精确同名结果，并在卡片中单独显示来源及链接。未找到、网络失败和同名歧义都有明确状态。音标、词性没有可靠数据时不填充。

## 数据与升级

旧词条保留 ID、原文、释义、原句、到期时间与连续记住次数。新增词条记录语种和精确位置；旧格式没有这些字段时仍可读取和复习。首页的「已掌握」指连续记住至少三次；「再学一次」清零并于十分钟后重现，记住后的复习间隔为 1、3、7、14、30、60 天。

累计与今日次数从本版实际完成的查询开始；最近六条查询保存在本机，重复查询会更新排序与时间。旧词本没有历史查询统计，不补造。关闭取词卡或发起新查询时旧任务应丢弃结果；编辑、取消或更换阅读语种后，过期全文译文不能回写。

数据仍在应用的本机偏好域，设置提供数据位置入口。遇到词本或活动数据无法解码时保留原始数据、显示错误，并禁止覆盖损坏部分。安装脚本复用现有签名材料；不要删除 `~/Library/Application Support/waxtranlate/BuildSigning`。本机升级备份存于 `~/Library/Application Support/waxtranlate/UpgradeBackups`，不提交到仓库。

## 复现验证

```sh
./scripts/check.sh
swift build -c release -j 2
```

检查使用隔离偏好域，覆盖真实 Vision OCR、精确命中、连续短语、非英语反例、旧词本、统计与跨日、最近六条、损坏数据保留、复习、过期阅读结果、术语歧义和百科请求边界。系统安装英中包时，另实测 Apple 翻译；未安装时明确打印跳过。GitHub Actions 的 macOS 工作流执行相同检查与 Release 构建，不修改屏幕录制权限。

真实界面回归需要手动完成：正常与窄窗首页；粘贴、全文翻译和双击第二个重复词；固定、展开、听读、复制与收藏；到期复习；更换快捷键与源语言；其他应用中的取词；框选与 Esc 取消。界面测试可用 `--test-profile WaxTranslate.Test.<唯一名称> --show` 启动隔离词本，完成后退出并删除该专用偏好域；不得使用真实用户词本作为测试夹具。安装签名、真实外部服务与界面验收的实测结果见 [本轮验收记录](verification/macos-sync/README.md)。
