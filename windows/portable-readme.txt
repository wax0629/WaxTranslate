WaxTranslate · Windows x64

完整解压文件夹，双击 WaxTranslate.exe。无需安装 Python，英译中模型已随包提供。
屏幕取词需要 Windows 英语 OCR。在「设置 → 时间和语言 → 语言和区域」中安装英语语言功能。也可在主窗口粘贴英文直接翻译。

主窗口粘贴英文后按 Ctrl+Enter 翻译，Ctrl+Shift+C 复制译文。
生词本里按 Ctrl+F 可以搜索单词、释义或原句。

轻按左 Ctrl 可查鼠标下的英文单词。较长的原句可以精简显示，点「查看全句」可对照完整译文。
词头下方显示语种和词性。按住头像、顶部或空白处可拖开浮窗，拖选正文可选中文字。
语种、英文词性和英译中均在本机处理。识别到其他语种时可复制原文。
按住左 Ctrl 并用左键拖动可翻译屏幕区域。点浮窗外可收起结果，Esc 可取消或关闭。
取词后点「收藏生词」，在「生词本」查看原句、译文并按到期时间复习。
关闭窗口后可从系统托盘打开或退出。再次启动会唤回已有窗口。

仅主动收藏的条目保存在 %LOCALAPPDATA%\WaxTranslate\notebook.sqlite3。
更新时退出旧版，解压新包到另一个目录即可。两个版本共用同一份生词本。
