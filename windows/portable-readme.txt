WaxTranslate · Windows x64

完整解压文件夹，双击 WaxTranslate.exe 后即可在系统托盘待命、直接取词。点击时钟旁的 WaxTranslate 图标（可能收在隐藏图标中），或再次双击启动器，可打开主窗口。无需安装 Python，英语、日语、韩语、法语、德语、西班牙语、意大利语、葡萄牙语和俄语译简体中文的模型已随包提供。
在「设置 → 原文语言」可选自动识别或指定语种，单独查短词时建议指定。屏幕取词使用 Windows OCR，手动选语种时需在系统「时间和语言 → 语言和区域」为对应语言安装文字识别。阅读日文、韩文和俄文屏幕内容需要相应的 OCR。也可切到「阅读」页直接粘贴原文，无需系统 OCR。

把鼠标指向网页、PDF 里的单词，轻按左 Ctrl 即可查词。可以先点首页的「试查 glance」，或把鼠标指向例句中划线的 glance 轻按取词键。首页下方可按需要选择「框选翻译」「对照阅读」或「生词本」。
在「阅读」页粘贴原文后按 Ctrl+Enter 翻译，Ctrl+Shift+C 复制译文。
第一次可以点「试读示例」，或者将文章粘贴到空白原文框。开启「单击查词」后点词即查，拖动可选字；关闭后仍可双击或按 Alt+Enter 查词。
读论文时，附近原文给出的缩写全称优先。ChatGPT、MVP 等术语、网络用语和英汉词典都能在本机查。本机未收录的英文词默认自动补查 Wikidata，仅发送所选词条。可在「设置」中关闭；升级沿用手动保存的选择。
在日语「図書館で」或韩语「도서관에서」中点中名词部分，可单查「图书馆」。
点「听读」听单词，右侧箭头可慢速重听或听完整原句。复习时也可听读。需要系统安装原文语种的声音。
生词本里按 Ctrl+F 可以搜索单词、释义或原句。

默认轻按左 Ctrl 可查鼠标下的单词。较长的原句可以精简显示，点「查看全句」可对照完整译文。
若与其他翻译软件冲突，在「设置 → 屏幕取词键」选择右 Ctrl 或「仅应用内查词」。
词头下方显示语种和词性。按住头像、顶部或空白处可拖开浮窗，拖选正文可选中文字。
语种识别和翻译均在本机处理。日、韩、法、德、西、意、葡、俄语经英语转译；英汉词典和词性标注用于英语。识别到尚未支持的语种时可复制原文。
按住设置的取词键并用左键拖动可翻译屏幕区域，也可点「框选翻译」。点浮窗外可收起结果，Esc 可取消或关闭。
取词后点「收藏生词」，在「生词本」查看原句、译文并按到期时间复习。
从主窗口或托盘右键菜单打开「设置」。开启「开机启动」后，下次登录 Windows 即在托盘待命。移动便携目录后，请在设置中点「改用当前版本」以更新旧启动项。
托盘可用时，主窗口不占用任务栏按钮。最小化默认收起到托盘；关闭窗口也默认收起，可在设置中改为直接退出。无系统托盘时会打开普通任务栏窗口。

主动收藏的条目、复习进度和当天的查词次数保存在 %LOCALAPPDATA%\WaxTranslate\notebook.sqlite3。
更新时退出旧版，解压新包到另一个目录即可。两个版本共用同一份生词本。

英文字体 Spectral 由 Production Type 设计，使用 SIL Open Font License 1.1，许可随包保存在 windows\fonts\OFL.txt。

WaxTranslate 字标使用 Archivo Black，字体许可随包存放在 windows\fonts。
